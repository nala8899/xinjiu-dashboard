三步开始使用
1. 点右上角「设置 / 分享」→「创建 / 连接云端空间」，然后把生成的分享链接发给供应商（任何网络都能打开，双方填写实时同步）
2. 在「喷塑中」页用「+ 大黑 / + 小黑 / + 蓝色」登记毛坯发喷塑的日期和数量，系统自动推算预计发货时间（在哪个板块点 +，新增的就是该阶段的记录）
3. 三个时间点分开处理：喷塑完点「标记发货」（可填少于喷塑数的实际发货量）→ 批次进「发货在途」；到货点「标记入库」填合格数与不良数 → 进「入库」；金蝶数据用「批量粘贴入库」直接导入；每天填写即时库存

设置 / 分享

尚未创建云端空间。创建后会生成一个分享链接，供应商（任何网络）打开即可看到并填写同一份数据。
📌 请复制下方「主链接」并收藏。它是带云端 ID 的永久链接，换设备、换部署域名打开都能自动恢复数据。
直接访问部署地址（不带 ?s= 参数）会显示空白——务必用这个带参链接。
两个链接看的是同一份云端数据，任何设备、任何网络打开都能看到最新进度。
区别：主链接可新增/修改/删除/改设置；供应商链接可填写批次表格（发喷塑日期 / 数量 / 预计发货时间 / 备注等），并可在「喷塑中」「发货在途」两页新增批次、可在「喷塑中」页标记发货，但不能删除、不能新增入库、不能改物料、不能标记入库、不能改设置。
国内长期使用推荐 腾讯云开发 CloudBase（国内节点、速度快、有免费额度）；免注册公共存储开箱即用，但不保证长期保留。
在腾讯云开发控制台做三件事：① 开通环境，复制环境 ID 填上面（形如 xxx-1a2b3c）；② 「登录授权」里开启匿名登录；③ 数据库新建一个集合（名字填上面），权限改成「所有用户可读，所有用户可写」。
① GitHub → Settings → Developer settings → Personal access tokens → 生成 token（勾选 gist 权限）；
② 把 token 粘贴到上面（仅存于你本机浏览器，供应商只读链接不含 token）；
③ 点「创建 / 连接云端空间」会自动生成公开 Gist 存数据。
提醒：api.github.com 国内访问时快时慢；token 请勿泄露，用完可随时在 GitHub 撤销。
填写「发喷塑日期」时自动推算「预计发货时间」
云服务不可用时，可用「数据码」通过微信把整份数据发给对方粘贴导入。本机每次保存前会自动留一份备份，误同步/误覆盖后可点「从本机备份恢复」找回上一版本。
